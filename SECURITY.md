# Security

## Reporting a vulnerability

Do not post exploit details, credentials, or private user data in public issues
or pull requests.

If GitHub private vulnerability reporting is enabled, use **Report a
vulnerability** in this repository's
[Security tab](https://github.com/Pippobaudoicon/rag-chat/security).

If that option is unavailable, check the
[maintainer's GitHub profile](https://github.com/Pippobaudoicon) for a private
contact method. If none is listed, open an issue asking for a private reporting
channel without disclosing vulnerability details.

Include in the private report:

- Affected commit or version and configuration relevant to the issue.
- A description of the impact and prerequisites.
- Minimal reproduction steps using accounts and data you control.
- A possible fix, if you have one.

Only include the information needed to reproduce the issue. Do not include live
secrets or other users' conversation content.

## Scope and updates

Reports may cover this repository's authentication, conversation ownership,
API access, data handling, and dependency vulnerabilities. Vulnerabilities in
external services should be reported to those providers.

There is no published security support schedule or response-time commitment.
Use the current default branch when reproducing a report and identify any older
version that is affected.

For ordinary bugs, setup questions, or incorrect AI answers, use
[SUPPORT.md](SUPPORT.md).
