# Support

For questions, reproducible bugs, and feature requests, use the
[GitHub issue tracker](https://github.com/Pippobaudoicon/rag-chat/issues).
Search existing issues first and add to a matching report when possible.

## Ask a question

Explain what you are trying to do, what you tried, and where you got stuck.
For local setup, check the [README](README.md), [.env.example](.env.example), and
[project knowledge base](docs/PROJECT_INFO.md) first.

## Report a bug

Include:

- Steps to reproduce, expected behavior, and actual behavior.
- Browser, operating system, and whether you used the installed PWA.
- For local builds, the commit or version, Node.js version, and pnpm version.
- Relevant sanitized error output or screenshots.

For an incorrect answer or citation, include a non-sensitive question, the
problematic excerpt, and the expected source link. The app also offers feedback
controls on answers.

Never post API keys, environment files, session tokens, billing information, or
private conversations. Remove personal information from screenshots and logs.
Security vulnerabilities follow [SECURITY.md](SECURITY.md).

## Suggest a feature

Describe the study or development problem and an example of the desired result.
For substantial changes, discuss the proposal in an issue before implementing it.

Issues are handled as maintainer time allows; no response-time commitment is
offered. GitHub support covers this project. Provider account and service issues
should go to the relevant provider.
