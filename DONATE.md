# Support ChatLDS

If ChatLDS helps with your study, you can support its continued development with
a voluntary donation. Support helps cover hosting, AI generation, embeddings,
and source retrieval costs.

not activate Pro features or increase your usage limits.

## Other ways to help

- Report bugs or suggest improvements through [SUPPORT.md](SUPPORT.md).
- Improve the code or documentation by following [CONTRIBUTING.md](CONTRIBUTING.md).
- Share ChatLDS with someone who might find it useful.

Thank you for supporting the project.
